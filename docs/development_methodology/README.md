# Work Requests Directory

This directory contains work requests for AI coding agents working on the APL Context-Aware project.

## Workflow

1. **PM creates work request** using the template in the documentation
2. **Copy request to this directory** for easy access by coding agent
3. **Coding agent reads request** and implements according to SLC framework
4. **Human verifies at checkpoints** as specified in the request
5. **Mark request as complete** and move to next sprint

Examples:

- `work-request-003-ui-context-display.md`

## Integration with PM Documentation

Work requests are created in the PM documentation directory first, then copied here for coding agent access. This maintains separation between planning and execution while providing easy access for the coding workflow.
